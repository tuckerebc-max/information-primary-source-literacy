# Information and Primary-Source Literacy

Standalone Codex skill package for `EXP-INFO` / `COMP-INFO-SOURCE`.

**Design state:** `READY_WITH_CONDITIONS` — review package, not a promoted universal standard.

The package operationalizes information-need formulation, strategic search, provenance, contextual interpretation, authority/relevance/sufficiency judgment, synthesis, ethical use, and uncertainty. The authoritative source/construct ledger is in `references/construct-and-source-ledger.md`.

## Package contents

- `SKILL.md` — operational skill workflow and guardrails.
- `agents/openai.yaml` — UI metadata.
- `references/` — source/construct ledger, output schema, and fixture contract.
- `shared/` — interoperable artifact schema.
- `tests/` — non-secure representative fixture.
- `scripts/` — local structural and fixture validators.
- `catalog/` — release, source, route, and finalization records.

The package does not reproduce protected assessment items or claim that a framework supplies a universal source-quality score.
